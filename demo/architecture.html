RENDERER · Three.js

Panels + street view

Off-axis render per panel (assumed spec), street-view simulation from the true eye, reference, ID dots, masks, street.mp4, delivery.mp4.

CHECKER · Python, independent

Geometry checks

C1 size · C2 reprojection (°) · C3 seams · C4 clipping · C5 readability · C6 sweet-spot map. → report.json

VERDICT

All hard checks pass?

Limits in config/thresholds.json (C2 max 0.28°), stamped by hash in every report.

OUTPUT

Certificate

certificate.json, panel video, street-view proof.

GEMINI 4 ARGON · A2

Repair

Watches street.mp4, reads the report and scene → diagnosis + JSON Patch.

GUARD

Patch guard

Only keyframes/scale/height/color · ≤ 6 ops · volumes · hero rule (no shrinking the product away).
